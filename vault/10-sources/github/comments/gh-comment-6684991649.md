## Conhecimento capturado

**Como criar o `dab-config.json`**

A forma recomendada é usar o **CLI do Data API builder (DAB)**. Ele gera o arquivo e você só ajusta depois se precisar.

---

### 1. Instalar o CLI

```bash
dotnet tool install -g Microsoft.DataApiBuilder
```

Verifique:

```bash
dab --version
```

---

### 2. Inicializar o arquivo (cria o esqueleto)

**Recomendado (connection string via variável de ambiente):**

```bash
dab init \
  --database-type mssql \
  --host-mode Development \
  --connection-string "@env('MSSQL_CONNECTION_STRING')" \
  --config dab-config.json
```

**Ou com connection string direta (só pra teste local):**

```bash
dab init \
  --database-type mssql \
  --host-mode Development \
  --connection-string "Server=localhost;Database=MeuBanco;User Id=usuario;Password=senha;TrustServerCertificate=True"
```

Isso gera um `dab-config.json` básico com a seção `data-source` e `runtime`.

---

### 3. Adicionar entidades (tabelas, views, procedures)

#### Tabela

```bash
dab add Clientes \
  --source "dbo.Clientes" \
  --permissions "anonymous:read" \
  --permissions "authenticated:*"
```

#### View

```bash
dab add VwPedidos \
  --source "dbo.vw_Pedidos" \
  --source.type view \
  --permissions "authenticated:read"
```

#### Stored Procedure (como ferramenta MCP customizada)

```bash
dab add ObterPedidoPorId \
  --source "dbo.usp_ObterPedidoPorId" \
  --source.type stored-procedure \
  --permissions "authenticated:execute" \
  --mcp.custom-tool true
```

#### Com descrição (ajuda o agente de IA)

```bash
dab add Produtos \
  --source "dbo.Produtos" \
  --permissions "anonymous:read" \
  --description "Catálogo de produtos com preço e estoque"
```

---

### 4. Habilitar MCP explicitamente (se não estiver)

Edite o `dab-config.json` e garanta que exista:

```json
"runtime": {
  "rest": { "enabled": true },
  "graphql": { "enabled": true },
  "mcp": { "enabled": true },
  "host": {
    "mode": "development"
  }
}
```

---

### 5. Exemplo final completo

```json
{
  "$schema": "https://github.com/Azure/data-api-builder/releases/latest/download/dab.draft.schema.json",
  "data-source": {
    "database-type": "mssql",
    "connection-string": "@env('MSSQL_CONNECTION_STRING')"
  },
  "runtime": {
    "rest": { "enabled": true },
    "graphql": { "enabled": true },
    "mcp": { "enabled": true },
    "host": {
      "mode": "development",
      "cors": { "origins": ["*"] }
    }
  },
  "entities": {
    "Clientes": {
      "source": {
        "object": "dbo.Clientes",
        "type": "table"
      },
      "permissions": [
        { "role": "anonymous", "actions": ["read"] },
        { "role": "authenticated", "actions": ["create", "read", "update", "delete"] }
      ],
      "description": "Cadastro de clientes"
    },
    "ObterPedidoPorId": {
      "source": {
        "object": "dbo.usp_ObterPedidoPorId",
        "type": "stored-procedure"
      },
      "permissions": [
        { "role": "authenticated", "actions": ["execute"] }
      ],
      "mcp": { "custom-tool": true }
    }
  }
}
```

---

### 6. Rodar

```bash
# Define a variável (Linux/macOS)
export MSSQL_CONNECTION_STRING="Server=localhost;Database=MeuBanco;User Id=usuario;Password=senha;TrustServerCertificate=True"

# PowerShell
$env:MSSQL_CONNECTION_STRING = "Server=localhost;Database=MeuBanco;User Id=usuario;Password=senha;TrustServerCertificate=True"

# Sobe em modo MCP stdio
dab start --mcp-stdio --config dab-config.json
```

---

### Comandos úteis depois

| Comando | Função |
|---------|--------|
| `dab update Clientes --permissions "anonymous:*"` | Altera permissões |
| `dab update Clientes --description "Nova descrição"` | Atualiza descrição |
| `dab validate` | Valida o arquivo |
| `dab start` | Sobe REST + GraphQL + MCP (HTTP) |

---

Quer que eu monte o `dab-config.json` já com as tabelas do seu banco? Me manda os nomes (ou um `SELECT name FROM sys.tables`) que eu gero os comandos `dab add` prontos.
