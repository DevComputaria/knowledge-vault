# Roadmap

| Fase | Entrega | Situação |
| --- | --- | --- |
| 1 | Issue → nota-fonte, manifest, MOC, Base e PR | MVP implementado |
| 2 | notas atômicas, aliases e links revisáveis | próximo |
| 3 | enriquecimento por LLM com JSON Schema | planejado |
| 4 | FTS5, embeddings e deduplicação semântica | planejado |
| 5 | relações tipadas e projeção em grafo | planejado |
| 6 | atualização, contradições e obsolescência | planejado |
| 7 | CLI, MCP, Graph RAG e agentes | evolução |

## Critérios para avançar

Cada fase deve preservar o texto original, incluir migração de schema, ser
reconstruível a partir do Markdown e passar por revisão humana. Infraestrutura
de busca ou grafo não se torna uma segunda fonte de verdade.
